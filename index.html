下载 SHA256SUMS.txt
为什么哈希不能写进安装包？ 文件自身的哈希依赖文件内容，写进去就改变了内容；而且哈希跟着文件一起传播，攻击者改完重算即可。 真正有效的是「签名」+「把哈希发布在文件之外」——本页两者都提供。

常见问题

安装前值得花一分钟了解的事。

Windows 提示「未知发布者」，是病毒吗？

不是。安装包使用自签名证书签名——它没有被公共 CA 背书，所以 Windows 不认识签发者。 签名本身仍然有效：任何对文件的改动都会让签名失效。若想消除提示，可把随附的 codesign-cert.cer 导入「受信任的根证书颁发机构」。

macOS 打不开，提示「无法验证开发者」怎么办？

macOS 包未签名、未公证。请在「系统设置 → 隐私与安全性」底部选择「仍要打开」， 或按住 Control 点击应用图标 → 打开。Apple Silicon 机器请下载 arm64 版本。

Android 该装哪个包？

不确定就用 universal 通用包。追求体积可用 arm64-v8a（近几年的手机基本都是）。 armeabi-v7a 面向 32 位旧设备，x86_64 面向模拟器。

怎么校验下载的文件？

Windows：certutil -hashfile 文件名 SHA256； macOS / Linux：shasum -a 256 -c SHA256SUMS.txt。 结果应与本页表格或 SHA256SUMS.txt 完全一致。
